# Git and GitHub

[Workshop index](../README.md)

- **[Read the shared Git guide](Git.pdf)**
- [Edit the LaTeX source](Git.tex)

One guide for Windows, macOS, and Linux: identity and authentication, local
practice, commits and diffs, ignore files, remotes, branches, pull requests,
conflicts, safe recovery, and privacy.

Git itself is installed using your OS guide; the workflow is not duplicated
across the OS handouts. Create the practice repository outside this workshop.

From `Computer_Literacy`, rebuild with:

```text
latexmk -cd -pdf -interaction=nonstopmode -halt-on-error Git/Git.tex
```
