Make local repo

    git init                    -- initialse a git repo locally on computer, this will show up as a .git folder

    echo "Read me file initialse" > README.md           -- make README file for repo

    git add .                                           -- this will stage you files 

    git commit -m "commit message here"                 -- makes first commit, locally

    touch .gitignore                                    -- makes .gitignore file
    git add .gitignore                                  -- use .gitignore

    # git config--global init.defaultBranch main        -- makes the main the defaultBranch

    # git remote -v             -- verify repo is fully local

    # ls -la .git               -- all version history on disk

    # git status                -- shows the current directory and current branch changes



Make local branch 

    git branch                  -- displays branchs

    git branch NewBranch        -- makes new branch named "NewBranch"

    git switch NewBranch        -- switches to new branch called NewBranch

    git branch                  -- verify which branch you are on

    git branch -d - NewBranch   -- remove branch named NewBranch

    git branch -D - NewBranch   -- force remove branch named NewBranch

    git branch -d - NewBranch   -- remove branch named NewBranch



Merge Branch to other branch

    git branch                  -- list branches
    
    git switch PrimaryBranch    -- change to the branch in which you would like to add another branch too

    git merge SecondaryBranch   -- merge the two branches together

    pip install numpy                   -- install packages
