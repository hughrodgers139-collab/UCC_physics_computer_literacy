The OS guides cover terminal use, project folders and paths, Python environments and editor shortcuts. 
They share the same learning goals but use the tools and commands for each platform.
Exercises are in the Python notebook.


## Setup and rebuilding

Clone the repository. Create a project virtual
environment and install the packages in [requirements.txt](requirements.txt)
using your OS guide.
