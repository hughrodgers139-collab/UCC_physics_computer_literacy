# Python and physics analysis

[Workshop index](../README.md)

- [Open the Python exercise notebook](Exersize.ipynb)
- [Synthetic linear-motion data](linear_motion.csv)

The notebook covers arrays, plots, tables, peaks, CSV input/output, model
fitting, residuals, uncertainties, exercises, and reproducibility. The CSV is
synthetic teaching data, not experimental measurements.

Create the environment using an [OS guide](../README.md) and
[requirements.txt](../requirements.txt), then select that environment as the
notebook kernel. Open `Example_Code` as the working directory before running
the notebook. Restart the kernel and run every cell from top to bottom before
sharing results.

The notebook writes `data_backup.csv` and `fit_result.pdf` in its working
directory; existing files with these names are overwritten. These generated
files are not backups. See the notebook's cited NumPy, Matplotlib, Pandas, and
SciPy documentation for the APIs used.
